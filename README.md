<h1>Wiki-Detective</h1>

A Python-based quiz game in which players test their knowledge of Berlin's famous landmarks.

<h2>About the Game</h2>

Wiki-Detective is a command-line quiz game built with Python. Players receive information about different Berlin landmarks and have to identify the correct location from four possible answers.

The game uses information retrieved from Wikipedia to create clues for each round.

<h2>How to Play</h2>

Enter the number of players.

Enter each player's name.

Each player takes turns answering questions.

Read the clue and choose the correct answer (A, B, C or D).

Earn points for correct answers.

At the end, the final ranking is displayed.

<h2>Technologies</h2>

Python

Wikipedia API (wikipedia-api)

Random module

<h2>Project Structure</h2>

main.py – Starts and runs the game.

game_logic.py – Contains the game mechanics and player interactions.

wiki_api.py – Retrieves information from Wikipedia.
